How it got here

The short version. The full write-up has every error and fix.

Getting in: TWRPSamsung rejected every custom vbmeta until we patched one byte (flags at offset 120) in Samsung's own, keeping its signature trailer.
The 32-bit wallThe A13 ships a 32-bit system; HyperOS 3 is 64-bit only. We built a hybrid vendor from the LineageOS Galaxy A21s (same Exynos 850 chip) plus 190 A13 files.
LineageOS 23.2 bootsAfter fixing lost file permissions and compiling kernel 4.19.325 ourselves.
HyperOS 3 bootsPatched Qualcomm-only graphics and media code to run on a Mali GPU, enabled XDP sockets in the kernel. Fifteen rounds to a stable boot.
Made usable64-bit-only apps, a touch-screen fix that speaks Samsung's display protocol, OpenGL rendering, a ported camera shim.
An AI assistantBuilt from scratch: plans long requests into steps and operates the phone.

Install

About 20 minutes. You need a Galaxy A13 4G SM-A135M (Exynos 850), an unlocked bootloader, and a PC with Odin (Windows) or odin4 (Linux).

⚠ Beta, flash at your own risk. Flashing erases all data on the phone; back up first. SELinux runs in permissive mode (less secure than stock). Don't use this phone for banking or sensitive work. Only for SM-A135M; other models may brick.
  1. Unlock the bootloader (Developer options → OEM unlocking, then the download-mode unlock). This wipes the phone.
  2. Download the files below and verify them with SHA256SUMS. Join the HyperOS parts with 7-Zip: open .7z.001 and extract; you get 2-hyperos-3.1-magisk.tar.
  3. Flash TWRP: boot into Download mode (Vol Up + Vol Down while plugging in USB), flash 1-twrp-vbmeta.tar in the AP slot.
  4. Format data: boot TWRP (Vol Up + Power right after flashing) → Wipe → Format Data → type yes.
  5. Flash the ROM: back in Download mode, flash 2-hyperos-3.1-magisk.tar (or 2-lineageos-23.2.tar) in AP.
  6. Boot and wait. The first boot takes a few minutes and the phone optimises apps once ("Compiling apps" notification). Install AIAssistant.apk and enable it in Accessibility to use the assistant.

Stuck? If boot fails three times the phone goes to TWRP by itself; flash again or restore stock firmware with Odin.
